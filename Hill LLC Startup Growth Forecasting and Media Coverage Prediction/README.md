# Hill LLC Startup Growth Forecasting and Media Coverage Prediction

## Project Summary

This project analyses startup growth data for Hill LLC Inc. from the perspective of a data scientist working for a venture capital investment firm. The main objective is to predict what the company may look like in 12 months by modelling payroll, revenue, and media coverage sentiment.

The project was completed using Python in Jupyter Notebook and applies data visualisation, linear regression, robust regression, log-transformed revenue modelling, and logistic regression.

## Business Problem

A venture capital investment firm is considering whether Hill LLC Inc. is a suitable company to invest in. To support this decision, the project uses historical company data to estimate future business performance.

The analysis focuses on three key questions:

- What will the company's payroll look like in 12 months?
- What will the company's revenue look like in 12 months?
- What is the likelihood of negative media coverage in 12 months?
- Are the model predictions reliable enough to support an investment decision?

## Dataset Used

The dataset used in this project is `hill_llc_startup_data.csv`. It contains 24 months of company-level data relating to payroll, revenue, scandals, and media coverage.

### Dataset Columns

- **Months_Since_Launch**: Numeric variable showing the number of months since the company was launched.

- **Payroll**: Numeric variable showing the total amount paid to employees during a specific month.

- **Revenue**: Numeric variable showing the total income generated by the company during a specific month.

- **Base_10_Log_Revenue**: Numeric variable showing the base-10 logarithm of revenue. This helps reduce skewness and supports linear modelling.

- **Scandals**: Numeric variable showing the number of scandals recorded in a specific month.

- **Media Coverage**: Categorical variable showing whether the company received positive or negative media coverage during the month.

## Analysis Performed

## 1. Data Import and Inspection

The dataset was loaded into a Pandas DataFrame and inspected using functions such as `head()`, `columns`, and basic exploratory checks. The purpose of this step was to understand the structure of the dataset, identify the available variables, and prepare the data for modelling.

## 2. Payroll Visualisation

A line plot was created to visualise payroll over time using `Months_Since_Launch` and `Payroll`.

The visualisation showed that payroll generally increased over time. However, one visible outlier appeared around month 10, where payroll was much higher than usual. This could represent a one-time event such as bonus payments, large hiring expenses, or restructuring costs.

## 3. Payroll Prediction Model

Two regression models were trained to predict payroll:

- Ordinary Least Squares Linear Regression
- Huber Regressor

The data was split into training, validation, and test sets. The training set included all months except the last two, the validation set used the second-last month, and the test set used the final month.

Mean Absolute Error was used as the evaluation metric because it clearly shows the average prediction error in dollar terms.

### Payroll Model Results

- OLS validation MAE: approximately **$1.51 million**
- Huber validation MAE: approximately **$602,918**
- Huber test MAE: approximately **$258,873**

The Huber regression model performed better because it is more robust to outliers. Since the payroll data contained a clear outlier, the Huber model was less affected by extreme values compared to ordinary linear regression.
